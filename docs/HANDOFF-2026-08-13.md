## 1. 项目速览

- **栈**: Rust + eframe/egui 0.29, 同一份代码双目标 native + wasm (GitHub Pages 部署)。
- **目录**: `~/xg-editor/` (AGENTS.md 常设文档 | TASKS.md 任务状态 | src/*.rs 源码 | www/ 部署目录)
- **发布**: push 到 main → GitHub Actions 自动构建 wasm + 部署 Pages。
  - Pages: https://johnskiller.github.io/xg-editors/ (当前 v0.1.21-8cc47bc)
  - 本机: `./build_wasm.sh 8090` → http://127.0.0.1:8090/

## 2. 最近已确认的工作 (全部已 commit/push, Pages 在线)

### 2.1 音色选择器 3 级钻取菜单 (commit `8cc47bc`)
- **交互**: params 面板 "pick" → egui 浮层菜单, 三级钻取:
  - 第一级: 类别 (GM 标准顺序, 非字母序) Piano→CP→Organ→Guitar→Bass→Strings→Ensemble→Brass→Reed→Pipe→Synth Lead→Synth Pad→Synth FX→Ethnic→Percussive→SFX→SFX Kit→Drum Kits
  - 第二级: 乐器, 显示 `PGM# 001  GrandPno` (PGM 1-based = prg+1)
  - 第三级: variations `lsb 000  GrandPno`; 单变体直接可点, 多变体子菜单
  - 长列表 (SFX 49 项) 限高 460px + ScrollArea 滚动
- **数据来源**: `src/data/mu90_voices.json` (include_str! 内嵌权威表, 606 条), 无分组字段。
  - 类别由 `msb+prg` 推导 (GM 16 区分区, `VoiceCategory::from_msb_prg`)
  - **MSB 映射**: 0=XG 音色区 (prg/8 决定类别), 64=SFX, 126=SFX Kit, 127=Drum Kits
  - `VoiceCategory::ALL` 是 GM 顺序常量 (18 个), label 在 data.rs
- **修过的坑**:
  - MSB=126 曾不在 Mu90 served_msbs → SFX Kit 不显示 → 修 device.rs `supported_msbs()` 为 `[0,64,126,127]` + 测试 `mu90_supported_msbs_lock`
  - 归类三档独立: SFX(64) / SFX Kit(126) / Drum Kits(127) — John 拍板分开
- **测试**: `voice_category_mapping_locked` (边界 prg 0/7=Piano, 8=CP, ... 127=Drum, 126=SfxKit), device.rs 测试。当前 **91/91 绿**。
